I asked the AI to compare my local folder structure with the evaluation criteria.

Result:
The AI inspected the project files, found that the generated output was initially written to output/triage_results.csv, and helped place the required predictions at support_tickets/output.csv.

My Design Decisions:
I chose a deterministic Python script rather than live LLM calls because it is reproducible, terminal-based, and easy for the evaluator to run.
I used the provided sample support cases as the grounding corpus.
I used conservative escalation for sensitive, ambiguous, or unsupported tickets to avoid hallucinated support policies.
I kept the project dependency-free so it can run with standard Python.
